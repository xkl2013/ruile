# 睿乐大脑 Flutter App

This directory contains the Android and iOS Flutter app for 睿乐大脑.

## Stack

- Flutter 3.x
- Dart 3.x
- Android and iOS platform projects generated by Flutter
- Material 3 UI

## Prerequisites

Install and configure:

- Flutter SDK
- Android Studio with Android SDK and an emulator or physical Android device
- Xcode and CocoaPods for iOS development on macOS

Check the local toolchain:

```bash
flutter doctor
```

## Development

From the repository root:

```bash
cd mobile
flutter pub get
flutter run
```

Useful commands:

```bash
flutter analyze
flutter test
flutter run -d ios
flutter run -d android
```

## Build

Android APK:

```bash
flutter build apk
```

iOS archive preparation:

```bash
flutter build ios
```

For a real iOS device or App Store build, open `ios/Runner.xcworkspace` in Xcode and configure the signing team and bundle identifier.

## Project Layout

- `lib/main.dart` - Flutter app entry and starter home page.
- `android/` - Android native project.
- `ios/` - iOS native project.
- `test/` - Flutter widget tests.
