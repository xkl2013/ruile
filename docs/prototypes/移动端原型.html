      演示开关

      本原型覆盖的关键设计点

      1. Tab 结构：记忆 / 整理 / 采集 / 发现 / 服务 —— 4 Tab + 中央采集键，保留移动端最强差异化能力。
      2. 「我的整理」（Web 的 mine）不单独占 Tab，作为整理工作台第二段，对齐 Web hub 的信息架构。
      3. 产物查看是「可扫可筛可跳」的视图，不是一篇长文：字段摘要在上、正文在下、[M1] 锚点可点回原始记忆。
      4. 移动端适配：卡片网格 → 1 列；卡片菜单 → 底部动作面板；右侧浮层面板 → 底部抽屉（界面说明 UI-Q7）。
      5. 任务时间线：自上而下由新到旧，被取代的历史任务灰显但保留。
      6. 采集链路（v1.1 新增）：中央键 → 录音页完整状态机 待开始 → 录音中 ⇄ 暂停 → 已保存/转写中。对齐现网 App 的 10:00 时长上限与「本地优先保存」策略；保存后命中「录音转写笔记」模板，可「立即整理」（PRD 的 auto_after_transcribe 语义）。
      7. 录音页演示方式：直接点手机里的麦克风 / 暂停 / 完成 / 取消，即可走完整个状态机，无需演示开关。
