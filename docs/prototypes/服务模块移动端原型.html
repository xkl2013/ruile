移动端边界与设计原则① 没有 hover —— web 的「服务行悬停 ＋」必须换成触摸等效；② 视口只有 390px —— web 的 320px 右侧浮层放不下，全部转整页或底部弹层；③ 零配置 —— 使用者只需要会聊天：新建服务 / 从模板创建 / 服务设置 / 重点记录编辑 / 成员管理 / 新增对象全部只在电脑端，移动端只留「聊天 + 看」；④ 形体按 WorkBuddy 移动端规范：状态栏 62px · 胶囊 tab bar（h62/r36/1px 边）· 激活态实心填充 · FAB 悬浮于底栏之上；⑤ 简洁优先：一屏一件事、一屏一个主按钮，同一条信息只出现一次，能一行说完就不做卡片 —— 目标是使用者一眼就知道怎么用。
