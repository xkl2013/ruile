# 睿乐大脑商业化建议与规划

> v1.0 · 2026-10-10 · 面向园所与教培机构的 AI 岗位产出平台
> 配套文档：`docs/幼教教培应用对标调研.md`、`docs/Agent模块设计方案.md`、`docs/招生顾问必用10个整理.md`、`docs/个人版与企业版实现设计.md`
> 适用范围：本文给出商业化判断、定价结构、收入模型与 12 个月路线图；所有价格数字为**建议区间**，需由真实销售验证后固化。

---

## 0. 一页结论

### 0.1 六条判断（结论先行）

1. **不要按"工具"卖。** 国内教培/园所 SaaS 的价格带已被卷到 499–3000 元/年（小禾帮 499 起、校管家 899 起、爱耕云 1000 起）。睿乐若按"席位 + 存储 + 积分"这套云资源口径报价，会被直接拖进这个价位，且覆盖不了 AI 成本。**要按"岗位产出"卖，锚 2–8 万/年。**
2. **AI 不是独立 SKU，是涨价的理由。** illumine 把 AI 免费塞进订阅、用它把客单价抬到 $249/$499；日本 チャイルドAI 反过来把 AI 单独卖 107.8 万日元/年。国内采购是预算制，**走"年费打包"更顺**；但首年必须收**配置费**——园所的死因不是买不起，是买了不会用。
3. **钩子只能落在"能出活"和"能招生"上。** 存储 GB、积分这些词园长听不懂也不关心。幼教/教培唯一愿意为软件加预算的理由是：**多招一个学生、少流失一个学生、少加一个人**。
4. **先只做一条线：招生。** 它是唯一能把 AI 支出直接换算成钱的场景，而且 10 个招生整理模板已上线（线上 v4/v3/v3），这是现成的付费样板。
5. **客群在萎缩，所以 ARPU 必须涨。** 全国在园幼儿一年减少 358 万（-10%），民办园一年减少 1.47 万所（-8.45%）。**存量市场的钱不在"多卖几家"，在"每家多收"**——这决定产品往"经营档"走，而不是往"低门槛铺量"走。
6. **两条红线不能碰**：① 不向家长收费（掌通家园部分地区向家长收费已被认定违规）② 不对儿童做保育判断、人脸识别、或用于训练第三方模型。

### 0.2 定价主张（建议区间）

| 档位 | 年费建议 | 卖什么 | 定价锚点 |
|---|---|---|---|
| 入门 · 记录 | **¥1.98 万/年** | 记忆 + 整理（能记能问，出整理报告） | 高于教培 SaaS 天花板（校宝 1 万），低于幼教区域服务商（3–8 万）下沿 |
| 标准 · 出活 | **¥3.98 万/年** | + 分身 Agent（四卡 + 技能层）+ 岗位专家 + 全量整理模板 | 幼教区域服务商 3–8 万区间中位 |
| 专业 · 经营 | **¥7.98 万/年** | + 招生转化链路 + 多园连锁 + 经营报表 + 数据接口 | 幼教头部（8–15 万）下沿 |
| 集团 · 私有化 | **¥20–50 万/年** | 私有化 + 定制模板 + 数据接口 + 驻场陪跑 | 智谱私有化 38 万/年、企业级 Agent 轻量档 20–50 万/年 |

一次性的**配置费 1–3 万**（首年）：含知识库搭建、模板配置、教师培训、4 周陪跑。

### 0.3 里程碑

| 时点 | 目标 |
|---|---|
| T+3 月 | 三档定价上架 + 支付闭环上线 + **3–5 家真实付费种子园**（验证付费意愿） |
| T+6 月 | 标准档（出活）成型 + 渠道签约 5–10 家 + 3 个可对外讲的效果案例 |
| T+12 月 | 经营档 + 连锁/私有化能力 + 渠道 50 家 + 续费机制跑通 |

### 0.4 一句话销售口径

> **"一年多留住 2 个孩子，这套系统的钱就回来了。"**

## 1. 市场与客群

### 1.1 大盘：幼教减量、托育与教培增量、付费能力上升

| 指标 | 数据 | 同比 |
|---|---|---|
| 全国幼儿园 | 23.19 万所 | −2.14 万所（−8.45%） |
| 在园幼儿 | 3225.52 万人 | −358.47 万（−10%） |
| 民办园 | 12.08 万所（占 52.10%） | −1.47 万所 |
| 民办园在园幼儿 | 1310.68 万人 | −197.32 万 |
| 普惠性幼儿园 | 20.31 万所（占 87.57%） | 占比提升 |

数据来源：教育部《2025 年全国教育事业发展统计公报》，转引自 2026 年学前教育行业分析。

早教/托育侧方向相反：

- 早教机构 **12.8 万家**（较 2021 年增长 87%），行业规模突破 **2800 亿元**，年复合增长率 14.5%；
- 2026 年多地试点托幼一体化财政补贴，**0–3 岁托育机构数量同比增长 34%**；
- 家庭户均学前教育年支出约 1.23 万元。

**三条解读：**

1. **可触达客群约 25 万家**（民办园 12.08 万 + 早教/教培 12.8 万）；但幼教侧是**减量市场**。
2. **增量在托幼一体化和市场化教培**——政策明确的第二增长点，也正好是睿乐"记忆 + 整理"最顺滑的场景（观察记录、健康、营养）。
3. **普惠园占 87.57%，受政府指导价约束**，付不起几万一年的软件费。**真正有预算的是民办特色园、连锁园、市场化早教/教培机构**——客群要按这条切。

### 1.2 政策：两个利好、一个压力

- **利好一**：2026-04 教育部等五部门印发《"人工智能+教育"行动计划》，明确鼓励 AI 赋能**校园管理、师资教研、幼儿发展评价**。睿乐的整理与 Agent 正好落在这三条上，可直接写进销售材料。
- **利好二**：2026-06 国务院《教育发展"十五五"规划》，推进托幼一体化建设。
- **压力**：2026-01 起《关于完善幼儿园收费政策的通知》统一规范收费项目，**只允许收五类合规费用，取缔赞助费与预交年费**。园所靠杂费创收的口子被堵，只能靠提高生均质量与口碑竞争 ⇒ **对"能提升留存与口碑"的工具是利好，对纯功能堆砌是利空**。

### 1.3 客群分层与优先级

| 优先级 | 客群 | 规模 | 付费能力 | 为什么排这个序 |
|---|---|---|---|---|
| P0 | 市场化早教 / 教培机构 | 12.8 万家 | 高 | 招生是命门，愿为线索与转化付费；效果可直接换算成钱 |
| P0 | 民办特色园 / 连锁园 | 12.08 万所中的中上部分 | 中高 | 有品牌诉求，需要"统一口径 + 出材料" |
| P1 | 托育机构 | 增长 +34% | 中 | 政策扶植，增量市场，场景最贴合 |
| P2 | 普惠园 | 20.31 万所 | 低 | 预算受限，只能走政府/协会集采通道（见 §6） |

## 2. 竞品定价锚点

### 2.1 三组价格带（对照用）

| 组 | 代表 | 价格 | 面向 |
|---|---|---|---|
| 国内教培 SaaS | 小禾帮 / 校管家 / 爱耕云 / 校宝 / 小麦助教 | **499–9800 元/年** | 机构（按校区或学员数） |
| 国内幼教 B2B（头部） | 掌通家园 / 智慧树 | **8–15 万元/年** | 园所（含硬件打包） |
| 国内幼教 B2B（区域） | 区域性服务商 | **3–8 万元/年** | 园所 |
| 国内幼教（轻量） | 贝聊 | 500–2000 元/年 | 按园所规模 |
| 企业 AI 平台 | 智谱清流 | 标准 **12.8 万元/年**；知识库私有化 **38 万元/年起** | 企业 |
| AI 助手（按人头） | 腾讯元宝企业版 / 飞书智能伙伴 / 钉钉斜杠 | 30–99 元/账号/月 | 按人头 |
| 企业级 Agent 项目 | 行业通用报价 | 轻量 RAG **20–50 万/年**；行业级 80–300 万 | 项目制 |

**三条读数：**

1. 教培 SaaS 被"价格屠夫"卷到 1000 元档，**纯工具定位没有定价权**。
2. 幼教 B2B 能到 8–15 万，因为它卖的是"硬件 + 视频 + 家长服务"的打包，**不是软件本身**。
3. AI 能力在国内企业侧的锚点是 **12.8 万元/年（标准档）**——这是睿乐"能力对得上"的档位。

⇒ **睿乐的定价不该对标教培 SaaS，应对标"幼教 B2B 中档 × 企业 AI 下沿"的交叉区，即 2–8 万/年。** 低于 2 万就落进教培 SaaS 的绞肉机；高于 8 万就与头部硬件打包方案正面冲突。

### 2.2 两个可直接复用的定价机制

1. **illumine 的 feature gating**：把"能收钱"的能力（账单与在线收款）卡在第二档，客单价直接 ×2.5（$99 → $249）。→ 睿乐的对应物是**「能出活」**（整理出正式交付物）与**「能招生」**（转化链路）。
2. **チャイルドAI 的"配置费 + 年费 + ID 数"**：初年度 107.8 万日元（初期设定 55 万 + 年费 52.8 万，30 ID 以内），次年起 52.8 万/年。它卖给园所的不是软件，是"**把你们园的理念与规程变成 AI 的判断标准**"这套配置服务。

## 3. 商业定位与价值主张

### 3.1 一句话定位

**不卖软件，卖"这家园/这个机构的岗位产出"** —— 把一线的记录（录音、观察、沟通、照片）变成直接能用的东西（复盘、台账、报告、清单），并落进系统成为可执行的动作。

### 3.2 口径改造：从"卖资源"到"卖产出"

| 维度 | 现在的口径（云资源） | 应改成的口径（岗位产出） |
|---|---|---|
| 分层依据 | 存储 GB / 积分 / 成员数 | 能记 / 能出活 / 能经营 |
| 客户听到 | "你买 100 GB 和 50 万积分" | "你的顾问每天早上自动收到一份谈单复盘" |
| 销售话术 | 便宜、容量大 | 多招几个、少走几个、少请一个人 |
| 续费理由 | 容量不够了 | 上个月靠它追回了 X 单 |

### 3.3 价值量化（销售必须能算的账）

以一家 15 个班、约 300 名孩子的民办园为例：

- 一个孩子一年学费约 **1.5–3 万元**（地区差异大）；
- 只要**多留住 2 个孩子**，就是 3–6 万元收入 —— **已覆盖最高档年费**；
- 对教培机构：一个顾问一年成交 30–60 单，**只要多成 1–2 单**，同样覆盖。

⇒ 销售口径统一为一句话：**"一年多留 2 个孩子就回本。"** 这是整套商业化里最有力的一句。

## 4. 产品分层与定价

### 4.1 能力矩阵（三档 + 集团版）

| 能力 | 记录档 1.98 万 | 出活档 3.98 万 | 经营档 7.98 万 | 集团版 20–50 万 |
|---|---|---|---|---|
| 记忆（录音 / 拍照 / 文字采集） | ✓ | ✓ | ✓ | ✓ |
| 整理（模板 + 周期任务） | 部分（3 个招生整理） | ✓ 全量 | ✓ | ✓ + 定制 |
| 分身 Agent（门面 + 四卡 + 技能层） | — | ✓ | ✓ | ✓ |
| 岗位专家包 | — | ✓ | ✓ | ✓ + 定制 |
| 招生转化链路（渠道归因 / 续费预警 / 投诉哨） | — | — | ✓ | ✓ |
| 多园 / 连锁管理 | — | — | ✓ | ✓ |
| 经营报表与导出 | — | 基础 | ✓ | ✓ |
| 数据接口 / 私有化部署 | — | — | — | ✓ |
| 成员上限 | 5 | 20 | 50 | 不限 |
| 存储 | 20 GB | 100 GB | 500 GB | 可配置 |

**gating 原则（照 illumine 的钩子逻辑）**：**"能出正式交付物"与"能招生"必须卡在付费档**；免费/入门档只给"能记能问"。

### 4.2 定价依据（三条）

1. **下限 1.98 万**：高于教培 SaaS 的天花板（校宝 1 万），低于幼教区域服务商 3–8 万的下沿 —— 既不跟价格屠夫打，也不跟硬件打包商正面撞。
2. **中位 3.98 万**：落在幼教区域服务商 3–8 万的中位 —— 客户心智里"一套园所系统"就是这个价。
3. **上限 7.98 万**：贴着幼教头部 8–15 万的下沿，用"AI 岗位产出"替代"硬件 + 视频"作为溢价理由。

### 4.3 配置费（首年一次性 1–3 万，建议必收）

**理由（有硬数据）**：行业实测，约 **40% 的园所低估教师培训成本**；而**提供使用培训的园所，家长与教师活跃度高出 47%**。幼教 SaaS 的头号死因不是价格，是**买了没人用、第二年不续**。

配置费包含四项：

1. 知识库搭建（园所规章、课程体系、话术入库）；
2. 模板配置与指令调校（对齐园所自己的口径）；
3. 教师培训（客户侧建议预留 2–3 周适应期）；
4. 首月陪跑（前 4 周每周一次回访）。

**这笔钱有两个作用**：① 提高首单金额、覆盖交付成本；② **筛掉不打算真用的客户**——愿意付配置费的才会真用，才会续费。

### 4.4 定价机制与工程落点

**关键事实：定价改配置即可，不需要开发。**

- 套餐 / 价格版本 / 商品 / 订单的后端管理能力已齐备：`internal/handler/billing.go`（`CreatePlan` / `UpdatePlan` / `CreatePriceVersion` / `CreatePurchaseItem` / `ListPaymentOrders` 等）；用户侧路由 `internal/router/router.go:402-420`（`/billing/catalog`、`/overview`、`/usage`、`/orders`）；前端 API `frontend/src/api/billing/`；后台页面 `admin/src/views/AdminBilling.vue`。
- 计费相关迁移已落地四组：`000086_billing_foundation`、`000087_billing_model_usage`、`000091_enterprise_billing_policies`、`000094_billing_operations`。
- 计费算法在 `internal/billing/pricing/`（Token / 按次 / 按秒 / 阶梯计价 + 价格快照），用量与预留见 `internal/application/service/usage_billing.go`。

**唯一要开发的是支付闭环**（`个人版与企业版实现设计.md` §20.3，TODO-P0-01 ~ TODO-P0-06）：订阅状态机、支付宝/微信在线支付、checkout、异步回调、用户自助购买、订单关闭与迟到回调。

➡️ **结论：把"三档定价上架"（零开发）与"支付闭环"（唯一工程依赖）作为 T+3 月的商业化关键路径。**

## 5. 收入模型（三情景）

### 5.1 混合 ARPU 推导

| 档位 | 年费 | 保守分布 | 基准分布 | 进取分布 |
|---|---|---|---|---|
| 记录档 | 1.98 万 | 70% | 45% | 25% |
| 出活档 | 3.98 万 | 25% | 40% | 40% |
| 经营档 | 7.98 万 | 5% | 15% | 35% |
| **加权 ARPU** | | **2.8 万** | **3.7 万** | **4.9 万** |

### 5.2 收入测算

| 情景 | 渗透率 | 客户数 | 混合 ARPU | 年订阅收入 |
|---|---|---|---|---|
| 保守 | 0.10% | 250 家 | 2.8 万 | **约 700 万元** |
| 基准 | 0.30% | 750 家 | 3.7 万 | **约 2800 万元** |
| 进取 | 1.00% | 2500 家 | 4.9 万 | **约 1.22 亿元** |

- 客群基数按 §1.1 的 25 万可触达机构计；渗透率为占基数的比例。
- 以上仅为订阅收入，不含私有化项目与增值服务。
- 三个情景均为假设，用于判断"要多少客户才能撑起什么量级"，不作为承诺。

### 5.3 收入结构建议（12 个月后目标占比）

| 收入类型 | 占比 | 说明 |
|---|---|---|
| 订阅（三档） | 70% | 基本盘，按园所/机构固定年费 |
| 配置 / 实施费 | 15% | 首年一次性，兼作落地质量闸门 |
| 集团 / 私有化项目 | 10% | 高客单、低频 |
| 增值（定制模板、专项陪跑、接口对接） | 5% | 按需 |

### 5.4 明确不做按人头收费

illumine 的原则值得直接引用：**"不因为多收孩子而惩罚园所"**。按人头/按孩子收费，客户增员时第一个砍你。**按机构固定年费 + 能力分档**才是幼教的正确形态。

## 6. 获客与渠道

幼教是**渠道驱动**行业（掌通家园靠代理制铺开），纯线上自获客效率低。五条路径：

| # | 路径 | 做法 | 预期贡献 | 注意 |
|---|---|---|---|---|
| 1 | 直营标杆 | 自建销售打 3–5 个样板园，做出可量化的效果案例 | 早期 100% | 必须产出"多留 2 个孩子"的实证 |
| 2 | 渠道代理 | 招区域代理（原幼教硬件 / 教具 / 信息化代理） | 中期主力 50%+ | 代理商不会讲 AI 价值 ⇒ 必须配标准话术 + demo 环境 + 分佣 |
| 3 | 教具 / 教材商合作 | 复制 チャイルド社模式（76 年教材商带 4000 园渠道） | 10–20% | 找有园所关系的出版 / 教具商做联合销售 |
| 4 | 园长社群 / KOL | 幼师口袋式内容运营，渗透园长社群 | 10% | 慢，但获客成本低，适合做品牌 |
| 5 | 政府 / 协会项目 | 教育局信息化集采、协会推荐 | 普惠园唯一通道 | 覆盖 20.31 万所普惠园只能走这条路 |

**销售物料必须包含四项**（否则渠道卖不动）：

1. 一页纸"回本算法"（多留 2 个孩子 = 回本）；
2. 3 个可展示的真实产物样例（谈单复盘、成长报告、经营日报）；
3. 政策背书页（《"人工智能+教育"行动计划》三处原文）；
4. 一个可自跑的试用环境（无需安装，扫码即进）。

## 7. 交付与留存

幼教 SaaS 的死因集中在交付，不在功能。三条硬要求：

1. **陪跑期不少于 4 周**（培训 + 每周回访），客户侧预留 2–3 周适应期；数据显示有培训的园所活跃度高 47%。
2. **第一份产出必须在 7 天内出现**。落地方式：开通当天就配置一个周期任务（如"到访谈单复盘 daily"），第二天早上自动出一条 —— 客户要尽快看到"这东西真能出活"。
3. **续费理由用数据讲**：到期前 30 天，系统自动生成一份"这一年你用它做了什么"的账（产出条数、覆盖家庭数、可归因的成交或留存），由销售带去谈续费。

> 工程提醒：周期任务调度时刻写死（`organize_workbench.go:1175-1204`，daily 08:00 / weekly 周一 09:00 / monthly 1 日 09:00），且时间词解析出的是**含未来的整段日历窗口**（`organize_selection.go:48-89`）。**交付时配置周期任务的指令必须写「上一个周期」（昨日/上周/上月）**，写「本周/本月/今日」会命中为空——这是交付 SOP 里必须写死的一条。

## 9. 风险与红线

### 9.1 六个风险

| # | 风险 | 影响 | 对策 |
|---|---|---|---|
| R1 | **客群萎缩**：在园幼儿 −10%/年，民办园 −1.47 万所/年 | 客户基数逐年下降 | 提 ARPU（往经营档走）+ 转向托育与教培增量 |
| R2 | **被卷价**：对手 499–1000 元/年 | 定价权丢失 | 坚决不打价格战，靠"能出活"划开档位 |
| R3 | **AI 成本失控** | 毛利被吃掉 | 已有积分制与用量预留（`internal/application/service/usage_billing.go`）；企业侧设成本护栏与超额策略 |
| R4 | **交付不落地**（最大风险） | 第二年不续 | 配置费 + 4 周陪跑 + 7 天内首份产出 |
| R5 | **合规** | 品牌与法律风险 | 见 9.2 红线 |
| R6 | **渠道不会卖** | 铺得出去、卖不出价 | 标准话术 + demo + 分佣 + 渠道培训认证 |

### 9.2 五条红线（不要碰）

1. **不向家长收费** —— 掌通家园部分地区向家长强制收 App 使用费已被认定违规。一切 C 端收费不做。
2. **不对儿童做保育、发育、行为的判断** —— AI 只做案头：起草、总结老师自己写的记录、标记异常。
3. **不对儿童做人脸或生物识别**。
4. **儿童照片与数据不得用于训练第三方模型**；配套租户隔离 + 角色可见性 + 审计日志。
5. **助手动作必须"先确认后执行"**（Famly 明写的产品原则），不做无人确认的自动动作。
