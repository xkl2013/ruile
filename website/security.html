SECURITY & DEPLOYMENT

孩子的数据在哪里，
必须由园所说了算。

睿乐大脑面向早幼教行业构建安全基线：支持本地与私有云部署，权限、加密、采集授权与审计全程可控，满足园所对家长与儿童数据的严格要求。

DEPLOYMENT

三种部署方式，按数据敏感度选择。

◫

本地部署

适合

对数据出园所有严格要求的单所园与集团。

说明

部署在园所自有服务器或一体机，Docker / Kubernetes 交付，支持离线安装，数据不出内网。

☁

私有云部署

适合

希望免运维、但要求资源独享的多园区机构。

说明

部署在指定云厂商的专属资源池，支持 Helm Chart 交付，网络与存储逻辑隔离。

◍

托管云（SaaS）

适合

快速起步的个人与小团队。

说明

开箱即用，托管模型与文档解析；数据按空间隔离，随时可迁移至私有化部署。

SECURITY CONTROLS

六层安全控制，覆盖数据的全生命周期。

◎

多空间 RBAC

Owner / Admin / Contributor / Viewer 四级角色矩阵，按知识库归属授权，附每空间审计日志。

🔒

静态加密

API Key 与 MCP / 数据源凭据 AES-256-GCM 加密存储，支持平滑密钥轮换。

✓

授权采集

音频、影像与手机资料按授权范围接入，支持脱敏处理与分级查看，杜绝无授权留存。

↔

传输安全

服务间 gRPC TLS + Token，Redis TLS，防 SSRF 的 HTTP 客户端覆盖数据源与 URL 导入。

▣

最小权限集成

权限范围 API Key：能力级授权、按知识库限制、last_used 追踪，程序化访问可控可审计。

⌕

全链路可观测

Agent 运行、解析进度、任务队列与审计日志全程可追踪，出问题可回溯到具体环节。

ONBOARDING CHECKLIST

部署前的四件事，
我们陪你一起确认。

01
采集授权范围

明确哪些岗位、哪些场景允许音频与影像采集，向家长与员工完成告知。

02
角色与空间规划

按园区 / 部门规划空间，指定每类角色的权限边界。

03
模型与数据归属

选择模型厂商与向量库方案，确认调用链路里数据的落点。

04
敏感信息处理

配置脱敏规则与分级查看策略，儿童与家长信息默认最小可见。
